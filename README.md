# Mellora Market Backend

Node.js and Express backend for Mellora Market, a premium MERN e-commerce platform.

## Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
- bcryptjs
- Axios API integration
- REST APIs

## Features

- User registration and login
- JWT-based authentication
- Product management
- Product search and filtering
- Shopping cart
- Wishlist
- Product reviews and ratings
- Checkout and orders
- Admin functionality
- MongoDB database integration
- API logging
- Seed data for products and admin user
